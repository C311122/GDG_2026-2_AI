- **이미지 도메인과 CNN의 특징:** 2차원 이미지를 1차원으로 펼치는 `Flatten`과 `Dense` 층은 픽셀 간의 공간적 구조를 잃어버리는 반면, CNN은 작은 필터를 통한 국소적 연결과 가중치 공유를 활용해 적은 파라미터로도 이미지의 주변 맥락과 이동 등변성을 효과적으로 학습함을 이해했습니다.
- **합성곱과 풀링의 하이퍼파라미터:** 필터가 학습하는 가중치인 파라미터와 개발자가 미리 설정하는 `kernel_size`, `strides`, `padding` 등의 하이퍼파라미터를 구분하고, 외곽 정보 손실을 막고 크기를 유지하는 Zero Padding과 특징을 요약해 연산량을 줄이는 Max Pooling의 역할을 익혔습니다.
- **2차원 연산 직접 구현:** NumPy를 활용해 이미지 테두리에 0을 채우는 `zero_pad_2d`, 3x3 커널을 슬라이딩하며 곱셈 합을 구하는 `conv3x3_valid`, 2x2 영역의 최댓값만 남기는 `max_pool2x2` 함수를 직접 코드로 구현하며 Feature Map이 생성되는 원리를 확인했습니다.
- **CNN 아키텍처 구현 및 Shape 변화:** Keras의 `Conv2D`, `MaxPooling2D`, `AveragePooling2D` 레이어를 조합하여 단순 CNN, LeNet-like, AlexNet-like 모델을 직접 구성하고, 각 층을 통과할 때마다 달라지는 Feature Map의 출력 Shape를 계산해 보았습니다.
- **모델 비교와 선택 기준:** Fashion-MNIST 데이터셋에 동일한 학습 조건으로 네 가지 모델을 학습시켜 비교한 결과, 무조건 파라미터 수가 많고 깊은 모델보다 데이터의 복잡도와 도메인 특성에 맞는 적절한 규모의 CNN 구조를 선택하는 것이 학습 효율과 정확도 면에서 유리함을 확인했습니다.
