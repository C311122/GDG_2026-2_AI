- **머신러닝과 딥러닝의 차이점:** 딥러닝은 인공신경망을 다층으로 구성한 머신러닝의 하위 분야로, 스스로 특징을 추출하며 대규모 비정형 데이터 처리에 강점이 있음을 배웠습니다. 반면 전통적인 머신러닝은 사용자가 직접 특징을 가공해야 하지만 결과의 해석 가능성이 높습니다.
- **인공신경망 및 활성화 함수:** 노드 간의 가중치와 편향을 이용해 연산하는 퍼셉트론의 구조를 이해하고, 이를 바탕으로 ReLU, Softmax, Sigmoid 등 다양한 활성화 함수를 코드로 직접 구현해 보았습니다.
- **Fashion MNIST 데이터 전처리:** 실습 데이터셋의 구조를 파악한 뒤, 원활한 학습을 위해 이미지 픽셀 값을 255로 나누어 0~1 사이로 정규화하고 2차원 배열을 1차원으로 평탄화(Flatten)하는 과정을 익혔습니다.
- **Keras 기반 모델 구축:**n 다중 분류 문제에서는 각 카테고리의 확률을 표현하기 위해 출력층에 Softmax 함수를 사용해야 한다는 점을 배웠습니다. 또한 1개의 Dense Layer로 이루어진 모델을 설계하여 입력과 출력 개수에 따른 가중치 및 편향의 총량을 직접 추론해 보았습니다.
